# SANCTUM — The Portfolio

The archive for **PROJECT SANCTUM** (Team CCA · TS ’26 Creative).

It opens as a title card. The ring takes three knocks. The door asks for `0528`. Then the Seal lifts and the files, lives, and write-ups are inside.

## Run

```bash
npm install
npm run dev
```

Preview host must allow the Arena / Vercel hostname (`vite.config.ts` already sets `host: true` and `allowedHosts: true`).

## Shortcuts

| | |
|---|---|
| Three knocks on the ring, then `0528` | the real way in |
| `?unlock` | skip the ritual (demo) |
| `~` | panic — the surface returns |
| footer *forget this visit* | wipe local unlock |
